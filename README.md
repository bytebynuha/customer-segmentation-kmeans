
# Customer Segmentation Using K-Means

## Problem Statement
Group customers based on age, annual income, and spending score
to understand customer purchasing behaviour.

## Objectives
- Load and explore customer data.
- Apply K-Means clustering.
- Choose K using the elbow method.
- Visualize customer clusters.
- Predict the cluster of a new customer.
- Containerize the application using Podman.

## Technologies
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Git and GitHub
- Podman

## Features
- Customer dataset display
- Elbow method visualization
- Interactive cluster selection
- Customer cluster visualization
- New customer cluster prediction
- Prediction history

## Dataset
The initial dataset contains synthetic demonstration data.
It is generated automatically by the application.

## Run Locally

Install dependencies:

    pip install -r requirements.txt

Start the application:

    streamlit run app.py

Open http://localhost:8501
